# Estudio Nodo — Sitio web

Sitio profesional para el estudio de arquitectura ficticio **Estudio Nodo**.

React + Vite · landing única · modo claro/oscuro.

## Instalación

```bash
cd estudio-nodo
npm install
npm run dev
```

## Build

```bash
npm run build
```

Salida en `dist/`.

## Despliegue

**GitHub:** sube el repo.

**Vercel:** Import → Vite → Build `npm run build` → Output `dist`.

No requiere variables de entorno.
